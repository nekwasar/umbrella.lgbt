# Umbrella.lgbt — Feature List

## Underage Safety Rules
- DOB collected at signup (mandatory)
- Under-18 profile: private by default
- Under-18 chats: locked until friend acceptance
- Under-18 cannot send/receive chat requests from 18+ users
- Friend acceptance only possible between same age group
- Age barrier is hard-locked, not bypassable
- Meet: under-18 and 18+ never see each other

## Age Transition (Under-18 → 18)
- On 18th birthday: account moves to adult space automatically
- Adult features unlock
- Existing under-18 friends who are also now 18+: connection stays
- Existing under-18 friends who are still under 18: lock re-applies until both are adult

## Fake Signups
- DOB dropdown at signup
- "You must be 13+ to use this app" checkbox (legal compliance)
- Community reporting for suspected underage users
- No ID upload. No face scan. No selfie verification.
- No invasive age verification. Trust the user. UX over paranoia.
- Worst case: a determined liar ends up in adult spaces — same as every other platform on Earth. Not worth degrading UX for honest users.
- 4 sections: Profile, Meet, Q&A, Community
- No homepage feed
- First landing after login: Profile page
- Unified color scheme
- Light retro aesthetic
- Profile + Meet: Spacehey-style UI
- Q&A + Community: old Reddit-style UI
