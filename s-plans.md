## Build Script Logic

```
1. Read content.json
2. For each page:
   a. Read content/[type]/[slug].md
   b. Choose template based on type
   c. If seeded:
      - Parse .md → HTML
      - Inject into template
      - <meta robots="index, follow">
   d. If unseeded:
      - Use placeholder template ("Coming soon")
      - <meta robots="noindex, nofollow">
   e. Write to public/[type]/[slug].html
3. Build home page from content/core/home.md + home.html template
4. Generate sitemap.xml (seeded pages only)
5. Generate robots.txt
```

---

## Page Lifecycle: Seeded vs Unseeded

| Element | Seeded | Unseeded |
|---------|--------|----------|
| Meta robots | `index, follow` | `noindex, nofollow` |
| In sitemap.xml | Yes | No |
| Visible to visitors | Full content | Title shown + "Coming soon" |
| Rendered HTML | Full page | Placeholder template |

## SEO Infrastructure

### sitemap.xml (auto-generated)
- Only seeded pages included
- Generated by build.js on every build
- Includes `<lastmod>` based on file modification date
- Includes `<changefreq>` (monthly for content, weekly for blog)

### robots.txt (auto-generated)
```
User-agent: *
Allow: /
Sitemap: https://umbrella.lgbt/sitemap.xml
```

### Per-Page Meta
- `<title>` — unique, includes page title + "| Umbrella.lgbt"
- `<meta description>` — unique per page (from frontmatter in .md or fallback)
- `<meta robots>` — `index, follow` (seeded) or `noindex, nofollow` (unseeded)
- `<link rel="canonical">` — full URL
- Open Graph: `og:title`, `og:description`, `og:image`, `og:url`, `og:type`
- JSON-LD structured data:
  - Organization schema (home page)
  - FAQ schema (Q&A pages)
  - Article schema (blog pages)
  - BreadcrumbList schema (all content pages)

### Internal Linking
- Blog posts link to related glossary terms and Q&A pages
- Q&A pages link to related Q&A questions
- Glossary terms link to related terms and Q&A
- City guides link to resource pages
- Breadcrumb nav on all content pages
